# Keyword Library

This folder holds the keyword-related source files for the SEO workflow.

## Files

- `seo_keyword_library_full.xlsx` - full master keyword library
- `seo_phase3_ordinary.xlsx` - ordinary-only split workbook
- `seo_phase3_pillar.xlsx` - pillar-only split workbook
- `seo_phase3_long_cycle.xlsx` - primary runnable workbook with pillar-first, ordinary-follow-up execution
- `seo_workflow_pack.xlsx` - base workflow keyword pack
- `seo_keyword_plan.md` - keyword planning and execution notes

## Recommended Usage

1. Use `seo_keyword_library_full.xlsx` as the keyword source of truth.
2. Use `seo_phase3_long_cycle.xlsx` as the default runnable workbook.
3. Treat `plan` as a pillar-priority and direction overlay, not as an exclusion list for ordinary keywords.
4. Use `seo_phase3_ordinary.xlsx` and `seo_phase3_pillar.xlsx` only as supporting operating files.
5. Keep all future keyword files in this folder for easier management.
