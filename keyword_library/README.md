# Keyword Library

This folder holds the keyword-related source files for the SEO workflow.

## Files

- `seo_keyword_library_full.xlsx` - full master keyword library
- `seo_phase3_long_cycle.xlsx` - primary runnable workbook with pillar-first, ordinary-follow-up execution
- `seo_phase3_long_cycle_part2..part5*.xlsx` - split slices of the long-cycle plan, used to run the batch in stages
- `done-seo_phase3_long_cycle_part1.xlsx` - part 1, already published (kept for reference)
- `seo_pending_43_standard_batch.xlsx` / `seo_pending_43_hourly_schedule.xlsx` - working queues for the currently pending batch of articles
- `seo_keyword_plan.md` - keyword planning and execution notes

## Recommended Usage

1. Use `seo_keyword_library_full.xlsx` as the keyword source of truth.
2. Use `seo_phase3_long_cycle.xlsx` as the default runnable workbook.
3. Treat `plan` as a pillar-priority and direction overlay, not as an exclusion list for ordinary keywords.
4. Use the `partN` slices and the `seo_pending_43_*` workbooks as operating files for the batch in flight.
5. Keep all future keyword files in this folder for easier management.

> The workbooks are generated by `scripts/generate_keyword_library_full.py`,
> `scripts/build_keyword_library_phase3.py` and `scripts/split_phase3_workbook.py`;
> the `plan` column overlays come from `seo_keyword_plan.md`.
